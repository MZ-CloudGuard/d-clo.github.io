### 2. 공유 설정

<center>
    <img
        src="../../../../assets/images/공유관리-3.png"
        width="1600"
        height="900"
        style="border: 1.5px solid black;"
    />
    <figcaption style="font-size:0.7em;">공유 설정 화면</figcaption>
</center>
① 종료 일자 : 공유 링크의 종료 일자를 변경합니다.<br>
　　- 설정된 일자가 지나면 링크가 차단되어 열람할 수 없습니다.<br>
　　- 이미 만료된 링크라도 종료 일자를 수정하면 재사용할 수 있습니다.<br>
② 일괄 다운로드 횟수 : 보고서를 다운로드할 수 있는 최대 횟수를 변경합니다.<br>
　　- 횟수가 모두 소진된 경우, 이곳에서 횟수를 늘려주면 늘린 횟수만큼 다운로드가 가능해집니다.<br>
　　- **진단 대상 1대 기준의 다운로드 횟수를 입력해주세요. 전체 공유 대상 수에 맞춰 총 횟수가 자동 산정됩니다.**<br>
　　　<span style="font-style:italic; color:#4B5563; font-size:0.9em;">EX) 공유 진단 대상당 일괄 다운로드 횟수 10회 자동 적용</span><br>
③ 다운로드 형식 : 공유 링크에서 제공할 보고서 형식(엑셀, 워드)을 설정합니다.<br>
④ 비밀번호 : 공유 링크 접속 비밀번호를 변경합니다.<br>
　　- 기존 비밀번호를 유지하려면 입력란을 비워 둔 채 저장합니다.<br>
　　- 비밀번호 복잡도 규칙<br>
　　　- 영문 대·소문자, 숫자, 특수문자 중 3가지 이상 조합<br>
　　　- 동일 문자 3회 연속 사용 제한(ex. aaa, 111 등)<br>
　　　- 연속된 문자/숫자 3자리 이상 사용 제한(ex. 123, abc 등)<br>
{: style="line-height:1.8;" }

**① 진단 목록 돌아가기**<br>
　- 공유 대상 목록 페이지로 돌아갈 수 있는 버튼입니다.<br>
**② 만료 정보 및 다운로드**<br>
　- 공유 링크의 만료 예정일과 남은 다운로드 가능 횟수를 표시합니다.<br>
　- 진단 보고서를 Word 또는 Excel 형식으로 다운로드 할 수 있습니다.<br>
**③ 진단 기본 정보**<br>
　- 현재 조회 중인 진단 대상의 기본 정보(진단 그룹, 생성 기준, 진단 ID, 진단 일시 등)를 표시합니다.<br>
**④ 종합 점수 및 직전 진단 대비**<br>
　- 해당 진단의 종합 점수와 등급을 표시합니다.<br>
　- 직전 회차의 진단 점수와 비교하여 상승·하락 변동 폭을 표시합니다.<br>
**⑤ 점검 항목 처리 현황**<br>
　- 전체 점검 항목의 취약, 양호, N/A 항목 개수와 비율을 표시합니다.<br>
　- 발견된 취약점의 개수를 위험 등급별로 분류하여 표시합니다.<br>
**⑥ 컴플라이언스 기준별 준수 점수** <span style="font-style:italic; color:#4B5563; font-size:0.85em;">※ 거버넌스 진단 결과일 경우 해당 영역은 노출되지 않습니다.</span><br>
　- 국내외 주요 보안 컴플라이언스 및 표준 가이드라인별 준수 점수와 등급별 세부 취약 항목 개수를 개별 카드로 표시합니다.<br>
**⑦ 취약이 발생한 서비스**<br>
　- 취약점이 발생한 서비스의 종류와 취약 건수를 표시합니다.<br>
　- 서비스별 점수와 위험도 비율 및 취약/양호 리소스 현황을 요약하여 제공합니다.<br>
**⑧ 취약 항목 목록**<br>
　- 진단에서 발견된 취약 항목의 세부 정보를 테이블 형태로 제공합니다.<br>
　- 필터 기능을 활용해 위험도 등급별 또는 서비스별로 데이터를 분류하여 조회합니다.<br>
