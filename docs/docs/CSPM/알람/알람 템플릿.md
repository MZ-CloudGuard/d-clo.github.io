알람을 받을 템플릿을 설정할 수 있는 페이지입니다.<br>
해당 페이지에서 account key, 템플릿 타입 및 공유 정책을 설정할 수 있습니다.<br>
<br>
진단이 완료되었을 때, 사용자가 정의한 세부 설정 기준에 부합하는 취약한 리소스가 발견되면 실시간 알람이 생성됩니다.<br>

## 알람 템플릿 생성 화면

### **1. 기본정보 입력**

<center>
    <img
        src="../../../../assets/images/알람템플릿-2.png"
        width="1600"
        height="900"
        style="border: 1.5px solid black;"
    />
    <figcaption style="font-size:0.7em;">기본정보 입력</figcaption>
</center>
- 템플릿 정보 입력 : 템플릿 이름 및 설명을 입력합니다.<br>
- 템플릿 타입 : 아래 3가지 유형 중 원하는 기준을 1개 선택하여 구성할 수 있습니다.<br>

| 유형                                                                                                                                        | 알람 발생 기준 (트리거)                                               | 추천 활용 목적                                       |
| :------------------------------------------------------------------------------------------------------------------------------------------ | :-------------------------------------------------------------------- | :--------------------------------------------------- |
| <img src="../../../../assets/images/icons/template-code.svg" alt="" style="height:1em; width:auto; vertical-align:-0.15em;"> **항목코드**   | 사용자가 **직접 선택한 항목 코드에 취약점이 발견**되었을 때           | 특정 보안 컴플라이언스나 취약점만 집중 모니터링할 때 |
| <img src="../../../../assets/images/icons/template-severity.svg" alt="" style="height:1em; width:auto; vertical-align:-0.15em;"> **위험도** | **선택한 위험도 레벨(High, Medium 등)에 취약점이 발견**되었을 때      | 위험 수준이 높은 취약점만 필터링하여 긴급 대응할 때  |
| <img src="../../../../assets/images/icons/template-service.svg" alt="" style="height:1em; width:auto; vertical-align:-0.15em;"> **서비스**  | **선택한 클라우드 서비스(예: EC2, S3 등)에서 취약점이 발견**되었을 때 | 인프라 서비스 단위로 담당자가 나누어져 있을 때       |

{: .nowrap-first-col }

<br>

### **2. 템플릿 정보**<br>

💡 **1개 이상**의 프로바이더를 선택할 수 있으며, 각 프로바이더별로 원하는 템플릿 세부 설정을 다르게 적용할 수 있습니다.
<br>

**(1) 항목코드 템플릿 설정**

<center>
    <img
        src="../../../../assets/images/알람템플릿-3.png"
        width="1600"
        height="900"
        style="border: 1.5px solid black;"
    />
    <figcaption style="font-size:0.7em;">항목코드 템플릿</figcaption>
</center>
- 알람을 받고자 하는 특정 항목 코드를 개별적으로 지정할 수 있습니다.<br>
- 진단 완료 시 사용자가 체크한 특정 항목 코드에 대해 취약 리소스가 발견되면 즉시 알람이 발송됩니다.<br>

**(2) 위험도 템플릿 설정**

<center>
    <img
        src="../../../../assets/images/알람템플릿-4.png"
        width="1600"
        height="900"
        style="border: 1.5px solid black;"
    />
    <figcaption style="font-size:0.7em;">위험도 템플릿</figcaption>
</center>
- 진단 완료 후 발견된 취약점의 위험도 등급을 기준으로 필터링합니다.<br>
- 지정한 위험도 수준에 해당하는 취약 리소스 항목이 발견될 경우 알람이 트리거됩니다.<br>

**(3) 서비스 템플릿 설정**

<center>
    <img
        src="../../../../assets/images/알람템플릿-5.png"
        width="1600"
        height="900"

    />
    <figcaption style="font-size:0.7em;">서비스 템플릿</figcaption>
</center>
- 특정 클라우드 자원 서비스를 기준으로 묶어 관리합니다.<br>
- 진단 완료 시 선택한 서비스 영역에 해당하는 취약한 리소스가 발견되면 알람이 전송됩니다.<br>

<br>

### **3. 진단 결과 공유 설정**<br>

<center>
    <img
        src="../../../../assets/images/알람템플릿-6.png"
        width="1600"
        height="900"
        style="border: 1.5px solid black;"
    />
    <figcaption style="font-size:0.7em;">진단 결과 공유 설정</figcaption>
</center>
① 공유 활성화 : 알람 발생 시 결과 요약 및 보고서 다운 가능한 공유 링크가 포함되어 발송됩니다.<br>
② 기간 : 공유 링크의 유효 조회 기간을 설정합니다.<br>
③ 다운로드 횟수 : 공유 링크 내에서 결과 보고서를 내려받을 수 있는 최대 횟수를 제한합니다.<br>
　- ```0```회 설정 시 다운로드가 금지되고 요약 열람만 가능합니다.<br>
　- 다운로드 횟수는 엑셀과 워드 보고서를 다운로드한 총합 횟수 기준입니다.<br>
④ 비밀번호 : 비인가자가 공유링크에 접근하지 못하도록 비밀번호를 설정합니다.<br>
　- 설정한 비밀번호는 수신자에게 별도로 안내해야 합니다.<br>
　- 비밀번호 복잡도 규칙<br>
　　- 영문 대·소문자, 숫자, 특수문자 중 3가지 이상 조합<br>
　　- 동일 문자 3회 연속 사용 제한(ex. aaa, 111 등)<br>
　　- 연속된 문자/숫자 3자리 이상 사용 제한(ex. 123, abc 등)<br>
⑤ 한줄 메시지 : 공유 링크 접속 시 요약 페이지 최상단에 노출할 안내 문구를 입력합니다.<br>
{: style="line-height:1.8;" }

<br>

## 진단 결과 공유 알람

알람 수신자는 진단이 완료되면 설정한 채널로 알람을 받게 됩니다.<br>
진단 결과 공유 활성화 여부에 따라 내용 구성에 차이가 있습니다.

**(1) ❌ 진단 결과 공유 기능 비활성화 [OFF] 시**

<center>
    <img
        src="../../../../assets/images/알람템플릿-7.png"
        width="400"
        height="500"
        style="border: 1.5px solid black;"
    />
    <figcaption style="font-size:0.7em;">진단 결과 공유 기능 [OFF]</figcaption>
</center>

- 메일 및 메신저 내 발견 리소스 개수에 대한 간략한 정보만 확인 가능합니다.
- <span style="color:#4472C4;">Link to D-CLO</span> 링크 접속하여 디클로 로그인하면 상세 정보 확인이 가능합니다.
- 디클로 계정이 없는 사용자가 알람을 수신받을 경우 상세 정보 확인이 불가능합니다.

**(2) ⭕ 진단 결과 공유 기능 활성화 [ON] 시**

<center>
    <img
        src="../../../../assets/images/알람템플릿-8.png"
        width="400"
        height="500"
        style="border: 1.5px solid black;"
    />
    <figcaption style="font-size:0.7em;">진단 결과 공유 기능 [ON]</figcaption>
</center>

- 공유 리포트 링크(<span style="color:#4472C4;">Open shared report</span>)가 내용에 함께 포함되어 발송됩니다.
- 공유 링크 비밀번호를 알고 있는 디클로 계정이 없는 사용자도 요약 정보 확인 및 보고서 다운로드가 가능합니다.

<br>
공유 리포트 페이지의 상세 구성 정보는 [공유 리포트](../진단 결과/보고서 공유 관리.md#공유-리포트) 가이드를 참고하시기 바랍니다.
<br>
생성한 알람 템플릿으로 알람을 설정하는 방법은 [알람 관리](알람 관리.md) 페이지 가이드를 참고하시기 바랍니다.
