- 알람을 신규 생성하거나, 기존 알람을 선택하여 수정 및 삭제할 수 있습니다.
- <span style="color:#4472C4;">활성화</span> 토글을 이용해 일시적으로 수신 차단할 알람을 설정할 수 있습니다.


## 알람 생성 화면
<center>
    <img
        src="../../../../assets/images/알람-2.png"
        width="1600"
        height="900"
        style="border: 1.5px solid black;"
    />
    <figcaption style="font-size:0.7em;">알람 생성 화면</figcaption>
</center>
① 수신 채널 선택 : 알람을 전송할 채널을 선택합니다. 1개 이상의 수신 채널을 중복하여 등록할 수 있습니다.<br>
② 알람 정보 입력 : 생성할 알람의 이름 및 설명을 입력합니다.<br>
③ 진단 대상 선택 : 진단 완료 시 알람을 추적할 대상(account key)을 지정합니다.<br>
④ 알람 템플릿 선택 : 알람을 트리거할 기준 템플릿을 선택합니다.<br>
　<span style="font-size:0.75em; color:#5459F0;">※ 알람 템플릿이 없을 경우 신규 생성이 필요합니다. </span> [→알람 템플릿 생성 가이드](../알람 템플릿_2.md) <br>
⑤ 채널별 연동 정보 입력 : 선택한 채널의 필수 연동 값을 입력합니다. (생성 방법 하단 참고)<br>
　　<img src="../../../../assets/images/icons/slack.svg" alt="Slack" style="height:1em; width:auto; vertical-align:-0.15em;"> **Slack** : Web hook URL <br>
　　<img src="../../../../assets/images/icons/jira.svg" alt="Jira" style="height:1em; width:auto; vertical-align:-0.15em;"> **Jira** : Instance URL, API key, Space Key, User Email <br>
　　<img src="../../../../assets/images/icons/teams.svg" alt="Teams" style="height:1em; width:auto; vertical-align:-0.15em;"> **Teams** : Web hook URL <br>
　　<img src="../../../../assets/images/icons/email.svg" alt="E-Mail" style="height:1em; width:auto; vertical-align:-0.15em;"> **E-Mail** : 수신용 이메일 주소 <br>
<br>
{: style="line-height:1.8;" }

### 💡 채널별 연동 정보 생성 방법
#### **1. Slack** <br>
Step 1) Slack API 페이지(api.slack.com/apps) 접속 후 로그인합니다.<br>
Step 2) Create an App 버튼을 클릭합니다.
<center>
    <img
        src="../../../../assets/images/slack-1.png"
        width="1600"
        height="900"
        style="border: 1.5px solid black;"
    />
</center>
Step 3) Blank app(또는 From scratch)를 선택한 후 Continue를 누릅니다.
<center>
    <img
        src="../../../../assets/images/slack-2.png"
        width="1600"
        height="900"
        style="border: 1.5px solid black;"
    />
</center>
Step 4) App Name을 입력하고 연동할 Workspace를 지정한 뒤 Creat App을 클릭합니다.
<center>
    <img
        src="../../../../assets/images/slack-3.png"
        width="1600"
        height="900"
        style="border: 1.5px solid black;"
    />
</center>
Step 5) 좌측 메뉴에서 Incoming Webhooks 항목으로 이동 후 Active Incoming Webhooks 스위치를 [ON]으로 활성화합니다.
<center>
    <img
        src="../../../../assets/images/slack-4.png"
        width="1600"
        height="900"
        style="border: 1.5px solid black;"
    />
</center>
Step 6) 페이지 하단으로 스크롤하여 Add New Webhook to Workspace를 클릭합니다.
<center>
    <img
        src="../../../../assets/images/slack-5.png"
        width="1600"
        height="900"
        style="border: 1.5px solid black;"
    />
</center>
Step 7) 알람 메시지를 게시할 Workspace 및 대상 채널(또는 사용자)를 선택하고 권한을 허용합니다.
<center>
    <img
        src="../../../../assets/images/slack-6.png"
        width="1600"
        height="900"
        style="border: 1.5px solid black;"
    />
</center>
Step 8) 생성된 Webhook URL을 복사합니다.
<center>
    <img
        src="../../../../assets/images/slack-7.png"
        width="1600"
        height="900"
        style="border: 1.5px solid black;"
    />
</center>

<br>

#### **2. Jira** <br>
**(1) Instance URL 확인**<br>
Jira에 로그인한 상태에서 브라우저 상단의 주소창을 확인합니다.<br>
```
🔗 형식
https://[회사명 또는 지정한 도메인].atlassian.net
```

**(2) API 토큰 생성** <br>
Step 1) Jira 계정 관리 페이지에 접속합니다.
<center>
    <img
        src="../../../../assets/images/jira-1.png"
        width="1600"
        height="900"
        style="border: 1.5px solid black;"
    />
</center>
Step 2) [보안(Security)] 메뉴로 이동합니다. <br>
Step 3) 페이지 하단의 API 토큰 만들기 및 관리를 클릭합니다. (필요 시 이메일 2차 인증 진행)
<center>
    <img
        src="../../../../assets/images/jira-2.png"
        width="1600"
        height="900"
        style="border: 1.5px solid black;"
    />
</center>
Step 4) API 토큰 만들기를 클릭하고 식별용 이름(Name) 및 만료 날짜를 지정한 뒤 만들기를 누릅니다.
<center>
    <img
        src="../../../../assets/images/jira-4.png"
        width="1600"
        height="900"
        style="border: 1.5px solid black;"
    />
</center>
Step 5) 생성된 토큰을 복사합니다<br>
<span style="font-size:0.84em;">**⚠️완료 버튼을 누르면 토큰을 다시 확인할 수 없으므로, 반드시 복사하여 별도로 임시 보관하세요.**
<center>
    <img
        src="../../../../assets/images/jira-6.png"
        width="1600"
        height="900"
        style="border: 1.5px solid black;"
    />
</center>

**(3) Space Key 확인** <br>
Step 1) 알람을 받을 스페이스에서 더보기 단추(...) 클릭하여 스페이스 설정을 클릭합니다.
<center>
    <img
        src="../../../../assets/images/jira-7.png"
        width="1600"
        height="900"
        style="border: 1.5px solid black;"
    />
</center>
Step 2) 설정페이지 내 스페이스 키 값을 확인합니다.
<center>
    <img
        src="../../../../assets/images/jira-8.png"
        width="1600"
        height="900"
        style="border: 1.5px solid black;"
    />
</center>

**(4) User Email**<br>
Jira에서 이슈 **보고자**로 지정할 사용자의 Email 정보를 입력합니다.

<br>
#### **3. Teams**<br>
Step 1) 알람 메시지를 수신할 Teams 내부의 팀 또는 채널로 이동합니다. <br>
Step 2) 채널 이름 우측 더보기 단추[···]를 선택한 후 **Workflows(워크플로)**를 클릭합니다. <br>
Step 3) 템플릿 목록 중 **'Send webhook alerts to channel'(채널로 웹후크 경고 보내기)**을 선택합니다. <br>
Step 4) 워크플로우 매개변수(알람이 포스팅될 채널 지정 등)를 구성하고 저장합니다. <br>
Step 5) 생성이 완료되면 화면에 출력되는 Webhook URL을 복사합니다. <br>
